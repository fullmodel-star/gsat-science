# 🧪 分科生物題庫（fenke-qbank）

大學分科測驗「生物考科」官方歷屆題庫 PWA，單檔離線可用。與學測生物／地科同一套引擎、相互獨立。屬「加深練習」——分科考選修生物Ⅰ-Ⅳ，範圍比學測廣。

## 內容
- **題源**：大考中心 分科測驗 生物考科 官方公開試題 **111–115**（5 年）。112–114 題目文字與題目圖取自翰林分科精彩解析 PDF 的「題目區」（＝大考中心試題，裁到答案行前）；**111、115 直接取自大考中心官方試卷**（.docx 文字＋.pdf 裁圖，2026-10-02 加入）。答案一律依大考中心公布（`check_qb.py` H 類逐題對官方答案 PDF）。**不收錄出版社詳解**（2026-10-01 翰林詳解下架）；**2026-11-13 起逐題解析為稜線編輯自寫**（241/242 題，畫面標示「稜線編輯撰寫，非官方解析」，見下方〈自寫解析〉）。
- **題數**：練習題 **186**（單選 124＋多選 62）＋ 混合題/非選 56 ＝ **242 題**（111：練習 38＋非選 9；115：練習 37＋非選 12；112–114：練習 111＋非選 35）。
- **章節**：選修生物Ⅰ 細胞與遺傳・Ⅱ 植物・Ⅲ 動物構造與生理・Ⅳ 生態與演化・生物(全)基礎。
- 圖表題內嵌官方原圖（裁切至答案行前、不洩答）；答案為官方公布。
