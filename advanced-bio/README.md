# 🧪 分科生物題庫（fenke-qbank）

大學分科測驗「生物考科」官方歷屆題庫 PWA，單檔離線可用。與學測生物／地科同一套引擎、相互獨立。屬「加深練習」——分科考選修生物Ⅰ-Ⅳ，範圍比學測廣。

## 內容
- **題源**：大考中心 分科測驗 生物考科 官方公開試題 **112–114**（3 年）；題目文字與題目圖取自翰林分科精彩解析 PDF 的「題目區」（＝大考中心試題，裁到答案行前），答案依大考中心公布。**不收錄出版社詳解**（2026-10-01 翰林詳解下架，逐題解析整理中）。
- **題數**：練習題 111（單選 74＋多選 37）＋ 混合題/非選 35 ＝ **146 題**（2026-10-01：F112-45／F112-48／F113-42／F114-40／F114-41 翰林答案為文字，實為非選題，改列非選）。
- **章節**：選修生物Ⅰ 細胞與遺傳・Ⅱ 植物・Ⅲ 動物構造與生理・Ⅳ 生態與演化・生物(全)基礎。
- 圖表題內嵌官方原圖（裁切至答案行前、不洩答）；答案為官方公布。

## 技術
- 單檔 `index.html`。localStorage key `fenke_qb_v1`；SW `fenkeqb-v1`；引導 `wc.fenke-qbank`。主題色 `#7c3aed`（紫）。與其他 App key 全分開。

## 翰林詳解下架（2026-10-01）
- 老闆決定：翰林出版社《精彩解析》的詳解不是試題、不受著作權法第 9 條保護，逐字收錄風險最高 → **全部下架，不改寫、不摘要**（改寫仍屬改作）。
- 每題 `expl`（詳解）與 `topic`（翰林測驗目標敘述）清空；作答後只顯示正確答案，原詳解位置改顯示「答案依大學入學考試中心公布。本題解析整理中。」；非選題顯示「本題解析整理中…請見大考中心公布的資料」。
- 保留：題目文字、題目圖／題組引文圖（大考中心試題內容）、答案（大考中心公布）、章節分類與難易度標籤（簡短分類，非解析文字）。
- 工具：`python _tools/strip_hanlin_expl.py`（可重複執行；`_build/inject_qb.py` 注入後會自動呼叫，避免詳解被重新灌回）。日後自寫的解析，把題目 id 加進該檔 `SELF_WRITTEN` 才會保留。
- 檢查：`python _tools/check_qb.py` 的 G 類（解析欄必須為空、index.html 不得有「翰林」「精彩解析」、原詳解文字不得殘留）。
