# 🧬 學測生物題庫（biogsat-qbank）

大學學測 自然考科「生物」部分的官方歷屆題庫 PWA，單檔離線可用。沿用學測英語題庫（gsat-qbank）引擎，改為生物版並擴充多選作答、圖表題、題組脈絡。

## 內容
- **題源**：大考中心 學測自然考科 官方公開試題 **111–115**（從自然合卷中抽出生物題）；答案依大考中心公布（112 起另與翰林精彩解析答案欄交叉核對）。**不收錄出版社詳解**（2026-10-01 翰林詳解下架，逐題解析整理中）。
- **題數**：練習題 69（單選 28＋多選 41）＋ 非選／混合題 9 ＝ **78 題**（2026-10-01：113-43、114-38 實為非選題，改列非選）。
- **每題**：題幹＋選項＋答案＋章節＋難易度（逐題解析整理中）；圖表題內嵌官方原圖；題組題附共用引文與共用圖。
- **答案品質**：已對大考中心官方答案交叉核對（0 誤）。

## 功能
- 整卷模擬（依年度・計時）／章節練習（細胞・遺傳・演化・延伸）／多選題特訓／每日一練／錯題本／收藏／弱點診斷／混合題非選瀏覽。
- 深色模式、考試倒數、PWA 可安裝、離線可用、進度存本機。

## 技術
- 單檔 `index.html`（題庫內嵌於 `const QB`）。
- localStorage 主 key：`biogsat_qb_v1`；SW 快取：`biogsatqb-v1`；引導命名空間：`wc.biogsat-qbank`。（皆與英語家族分開，不互相污染）
- 主題色 `#059669`（生物綠）。

## 資料重建
題庫由 PDF 自動抽取建置：官方試卷解析(骨架)＋翰林解析(答案/章節；詳解已於 2026-10-01 下架)以題號合併，111 舊版以內容相似度對接；圖表題與題組圖以 PyMuPDF 裁切官方 PDF。

## 題庫資料修正（2026-10-01）
- 原建置管線（`_封存_舊中文結構/_build`：build_subject→finalize→assemble）已無法重現現行題庫（章節、111 配對、gid 皆會變），**不要整條重跑**。
- 改用疊加修正：`python _build/fix_20261001.py`（以 `qb_*.pre20261001.json` 為底、重讀同一套原始 PDF）→ `python _build/inject_qb.py`（只換 index.html 的 `const QB` 那一行）。
- 檢查：`python _tools/check_qb.py`（選項數、題組引言混入、引用圖表有圖、殘圖、翰林答案比對；0 違規才可發版）。
- 純圖選項題用 `optKeys` 記錄原卷實際選項字母（不再一律 A–E）；沒有可作答選項的題目不會進入任何練習。

## 翰林詳解下架（2026-10-01）
- 老闆決定：翰林出版社《精彩解析》的詳解不是試題、不受著作權法第 9 條保護，逐字收錄風險最高 → **全部下架，不改寫、不摘要**（改寫仍屬改作）。
- 每題 `expl`（詳解）與 `topic`（翰林測驗目標敘述）清空；作答後只顯示正確答案，原詳解位置改顯示「答案依大學入學考試中心公布。本題解析整理中。」；非選題顯示「本題解析整理中…請見大考中心公布的資料」。
- 保留：題目文字、題目圖／題組引文圖（大考中心試題內容）、答案（大考中心公布）、章節分類與難易度標籤（簡短分類，非解析文字）。
- 工具：`python _tools/strip_hanlin_expl.py`（可重複執行；`_build/inject_qb.py` 注入後會自動呼叫，避免詳解被重新灌回）。日後自寫的解析，把題目 id 加進該檔 `SELF_WRITTEN` 才會保留。
- 檢查：`python _tools/check_qb.py` 的 G 類（解析欄必須為空、index.html 不得有「翰林」「精彩解析」、原詳解文字不得殘留）。
