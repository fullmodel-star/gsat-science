# 🌏 學測地科題庫（escgsat-qbank）

大學學測 自然考科「地球科學」部分的官方歷屆題庫 PWA，單檔離線可用。與學測生物題庫同一套引擎、相互獨立。

## 內容
- **題源**：大考中心 學測自然考科 官方公開試題 **111–115**（地科僅出現在學測自然、無分科測驗）；答案依大考中心公布（112 起另與翰林精彩解析答案欄交叉核對）。**不收錄出版社詳解**（2026-10-01 翰林詳解下架，逐題解析整理中）。
- **題數**：練習題 62（單選 36＋多選 26）＋ 非選／混合題 8 ＝ **70 題**。
- **章節**：地球的故事・從地球看宇宙・千變萬化的大氣・深藍的脈動・體驗大地的撼動・鑑古知今談永續（地科全六章）。
- 圖表題內嵌官方原圖；題組題附共用引文與共用圖；答案已對官方核對。

## 技術
- 單檔 `index.html`。localStorage 主 key：`escgsat_qb_v1`；SW：`escgsatqb-v1`；引導：`wc.escgsat-qbank`。主題色 `#0284c7`（天空藍）。與生物版／英語家族 key 全分開。

## 翰林詳解下架（2026-10-01）
- 老闆決定：翰林出版社《精彩解析》的詳解不是試題、不受著作權法第 9 條保護，逐字收錄風險最高 → **全部下架，不改寫、不摘要**（改寫仍屬改作）。
- 每題 `expl`（詳解）與 `topic`（翰林測驗目標敘述）清空；作答後只顯示正確答案，原詳解位置改顯示「答案依大學入學考試中心公布。本題解析整理中。」；非選題顯示「本題解析整理中…請見大考中心公布的資料」。
- 保留：題目文字、題目圖／題組引文圖（大考中心試題內容）、答案（大考中心公布）、章節分類與難易度標籤（簡短分類，非解析文字）。
- 工具：`python _tools/strip_hanlin_expl.py`（可重複執行；`_build/inject_qb.py` 注入後會自動呼叫，避免詳解被重新灌回）。日後自寫的解析，把題目 id 加進該檔 `SELF_WRITTEN` 才會保留。
- 檢查：`python _tools/check_qb.py` 的 G 類（解析欄必須為空、index.html 不得有「翰林」「精彩解析」、原詳解文字不得殘留）。
